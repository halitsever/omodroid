# An open source launcher for the Omoda 5 head unit, in planning

Omodroid is a planned Android launcher and overlay for the infotainment head unit of the Omoda 5 (2023). It is meant for owners who want to customize that screen. This page says what the project is, what is already known about the car's screen from Chery's documents, and what is still open. The short version: there is nothing to install yet.

## What Omodroid is planned to be

The README states the goal in one line: an Android launcher and overlay for the Omoda 5 (2023) infotainment head unit.

- **Launcher:** the home screen app that starts other apps. The [launcher explainer](/android-car-launcher) describes what that means on a car screen.
- **Overlay:** a window drawn on top of other apps, for a small piece of information or a control that stays visible.

That sentence is the whole published plan. The project has no feature list, no roadmap and no release date, so this page does not invent one.

## What Chery's documents say about the screen

From [Chery Australia's OMODA 5 brochure (MY24, January 2025)](https://cherymotor.com.au/sites/default/files/2025-01/OMODA-5-Brochure-MY24-JAN2025.pdf), the most detailed document Chery publishes for the model:

| Item                           | Brochure                                               |
| ------------------------------ | ------------------------------------------------------ |
| Screens                        | Dual 10.25 inch LCD instrument cluster and touchscreen |
| Apple CarPlay and Android Auto | Wired and wireless                                     |
| Voice command                  | "Hello Chery"                                          |
| USB with data                  | Front USB Type-A                                       |

Equipment differs between markets and model years. Turkish owners can read a summary in Turkish in the [Omoda 5 multimedia screen post](/blog/omoda-5-multimedya).

## What is not known

- What operating system the head unit runs. Chery does not document it, and this project does not guess.
- Whether the unit lets you install apps or change the home screen.
- Which software versions Omodroid will support. Nothing has been built or tested.

Until code exists, these stay open questions. Methods passed around on forums can damage the car's software or affect the warranty; this site does not describe them.

## What you can use today

If you want your phone's apps on the screen now, use the car's own phone projection. The [Android Auto troubleshooting checklist](/blog/android-auto-not-working) follows Google's help pages if it does not connect, and [Android Auto vs a head unit vs a launcher](/blog/android-auto-vs-head-unit) explains how a launcher would differ.

## Follow the first release

- **Watch** the [repository on GitHub](https://github.com/halitsever/omodroid) and choose release notifications.
- **Ask or suggest** in the [issue tracker](https://github.com/halitsever/omodroid/issues).
- **Read** the [project status](/status) for how to open a useful issue or send a pull request.

## FAQ

### Can I install an Omoda 5 launcher today?

Not from this project. Omodroid has no source code, no release and no install steps yet. The README says install steps will be added with the first build.

### Which features will the launcher have?

None are published. The README describes the goal in one line, an Android launcher and overlay for the Omoda 5 (2023) head unit, and no feature list or roadmap exists yet.

### Does the Omoda 5 already support Android Auto and CarPlay?

Chery Australia's OMODA 5 brochure lists Apple CarPlay and Android Auto, wired and wireless. Equipment differs by market and year, so check the documents for your own car.

### Is Omodroid made by Chery or Omoda?

No. It is an independent open source project by Halit Sever, not affiliated with, endorsed by or sponsored by Chery or Omoda.
